# Kebutuhan Sistem

## Kebutuhan Fungsional
| ID | Kebutuhan |
|----|-----------|
| FR-01 | Pengguna dapat menambah, mengubah, dan menghapus data suku cadang |
| FR-02 | Pengguna dapat mencatat barang masuk dan barang keluar |
| FR-03 | Sistem menghitung stok terkini secara otomatis |
| FR-04 | Sistem menampilkan daftar barang dengan stok di bawah batas minimum |
| FR-05 | Pengguna dapat mencari suku cadang berdasarkan nama atau kategori |

## Kebutuhan Non-Fungsional
| ID | Kebutuhan |
|----|-----------|
| NFR-01 | Aplikasi berjalan otomatis sebagai service dan restart bila gagal |
| NFR-02 | Tidak ada kredensial di dalam repository |
| NFR-03 | Akses ke GitHub memakai deploy key |
| NFR-04 | Dokumentasi tersedia untuk instalasi dan deployment |
